# 强势向上跳空缺口 v2.1

日线收盘后规则策略：D0 必须形成未复权实体向上缺口、明显放量、强势收盘和近期突破；D1 验证原始缺口是否获得承接；通过后 D2 获得正常交易资格。D2收盘后不机械延期D1资格，而是使用D2新增行情独立评价D3延续入场。

SHORT_GAP V0 使用 0.5% 缺口和 1.5 倍过去20日成交量中位数作为候选入口。前置涨幅、平台振幅和平台漂移不再单独否决候选，而是进入质量分和风险标签。满足原 1% 缺口、2倍量比及严格趋势平台条件的候选同时标记为 STRICT_GAP。

D1 完整回补原始缺口立即失效；部分回补后收盘重新站回 `gap_top` 可获得带风险的 D2 资格；部分回补且未收回不进入默认推荐；完全未回补属于较强承接。停牌或数据缺失不能被当成未回补。

`structure_validity` 与 `entry_validity` 独立：D2最低价触及 `gap_floor` 才是结构失效；结构仍在但进入衰竭、收盘位置低于60%、收盘未站上 `gap_top`，或相对D0收盘扩张达到10%，只会关闭新开仓资格。满足全部条件时产生D3 `continuation_entry`。D2停牌或一字涨停造成的 `execution_rollover` 仍是独立的客观不可成交顺延，不与延续入场混用。

回测为同一信号保存共享 `comparison_pair_id` 的 D2 `early_entry` 与 D3 `continuation_entry` 事件，分别输出入场后1、2、3、4、5日收益、MFE、MAE、完整回补和分组结果。所有阈值均为工程参数；缺少 PIT 沪深300历史成分和证券状态时，不得声称参数有效。
