# 强势向上跳空缺口 v1

日线收盘后规则策略：前置上涨、十日横盘、未复权实体缺口、成交量放大和强势收盘全部满足时，D0 进入观察；D1～D3 任一天完全回补即失效，三天均未完全回补才在 D3 收盘确认。

缺口几何使用未复权日线，趋势和平台漂移使用前复权日线。排序分只用于解释性排序，不是上涨概率。第三个及之后仍未回补的缺口标为衰竭风险，默认不进入确认推荐列表。

合法一字线因 `open == high == low == close` 无法满足普通阳线的 `close > open`，因此作为唯一例外继续接受其他硬条件检查，同时标记 `one_price_limit_risk`；后续回测仍必须证明实际可成交。
