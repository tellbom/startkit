# 强势向上跳空缺口 v2

日线收盘后规则策略：D0 必须形成未复权实体向上缺口、明显放量、强势收盘和近期突破；D1 验证原始缺口是否获得承接；通过后 D2 才获得最早交易资格。D2、D3 及之后的数据用于入场后的强弱验证，不再等待到 D3 才确认。

SHORT_GAP V0 使用 0.5% 缺口和 1.5 倍过去20日成交量中位数作为候选入口。前置涨幅、平台振幅和平台漂移不再单独否决候选，而是进入质量分和风险标签。满足原 1% 缺口、2倍量比及严格趋势平台条件的候选同时标记为 STRICT_GAP。

D1 完整回补原始缺口立即失效；部分回补后收盘重新站回 `gap_top` 可获得带风险的 D2 资格；部分回补且未收回不进入默认推荐；完全未回补属于较强承接。停牌或数据缺失不能被当成未回补。

回测分别输出入场后1、2、3、4、5日收益、MFE、MAE、完整回补和分组结果，默认只允许 D2 入场并在最多5日退出。D3延迟入场与4日退出只能作为显式配置方案独立回测。所有阈值均为工程参数；缺少 PIT 沪深300历史成分和证券状态时，不得声称参数有效。
