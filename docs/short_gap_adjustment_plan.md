# `strong_gap_up_v1` 短线化策略调整计划

> 文档状态：v2 策略口径已实现；PIT参数验证和“同一上涨阶段”最终切分仍未完成。v1历史结果继续保留，不与v2配置哈希混写。
>
> 调整目标：不新增独立策略，不改变真实向上缺口的核心，只把交易时钟从“D3 确认后追趋势”调整为“D0 发现、D1 验证、D2 参与、未来 1～3 日兑现，最迟 4～5 日退出”。

## 1. 本轮裁决边界

本轮只调整现有 `strong_gap_up_v1` 的策略口径。以下边界冻结：

- 股票池仍为当日 PIT 沪深 300；ST、`*ST`、退市整理、北交所、上市不足 60 个自然日、停牌及数据不完整证券继续排除。
- 继续使用未复权价格判断缺口几何，使用前复权价格评价跨期趋势。
- 不引入机器学习、MACD、KDJ、RSI 或另一套技术指标体系。
- 不把策略改成普通突破、追涨停或一般趋势跟踪。
- 不以“每天必须有候选”为目标；没有真实结构时允许返回 0。
- 所有阈值均为可版本化的 V0 工程参数。没有 PIT 历史回测证据前，不得描述为最优参数或有效胜率阈值。

## 2. 策略时钟

```text
D-1          D0                   D1                    D2             D3～D5
前一交易日 -> 发现真实向上缺口 -> 收盘验证缺口承接 -> 最早允许交易 -> 持仓验证与时间退出
                 只生成候选          决定是否可参与        不再等待D3      不无限延长
```

- D0：发现异常启动，只生成待确认候选，不能用 D1 数据反向筛选。
- D1：核心确认日。D1 收盘后才可获得交易资格。
- D2：由交易日历确定的下一交易日，是最早模拟入场日。
- D2、D3：用于评价入场后的短期强弱，不再是入场前置确认。
- 主要收益观察期为实际入场后的 1、2、3 个交易日；同时观察 4、5 日，策略持有不得无限延长。
- A 股 T+1 约束不变：入场当日即使失效，也不能假设当日卖出。

## 3. 冻结的缺口定义

D0 必须形成真实向上缺口：

```text
gap_floor = raw_high[D-1]
gap_top   = raw_low[D0]
gap_pct   = gap_top / gap_floor - 1
raw_low[D0] > raw_high[D-1]
```

`gap_floor` 和 `gap_top` 在信号生成后永久引用原始 D0 缺口，D1～D5 不得滚动修改。后续状态统一按以下几何关系解释：

- `low <= gap_floor`：完整回补，原始逻辑失效。
- `gap_floor < low < gap_top`：部分回补。
- `low >= gap_top`：完全未回补。

等于 `gap_floor` 视为完整回补；等于 `gap_top` 视为未进入缺口。

## 4. D0 候选分层

### 4.1 SHORT_GAP 硬条件

SHORT_GAP 是实际短线候选入口，以下条件必须全部满足：

1. 通过股票池、证券状态、上市日数、可交易性和数据完整性检查。
2. D0 前至少具有当前配置要求的有效历史日线。
3. `raw_low[D0] > raw_high[D-1]`。
4. 缺口宽度达到 SHORT_GAP 的最低入口。
5. D0 成交量相对过去 20 个交易日中位数存在明显放大，分母不包含 D0。
6. D0 是阳线，或是合法一字线并显式携带不可成交风险。
7. D0 收盘位置具有强势特征。
8. D0 收盘价突破此前 10 个交易日最高价。

用于首轮开发和对比回测的 V0 候选参数为：

| 参数 | SHORT_GAP V0 | 性质 |
|---|---:|---|
| 最小缺口 | 0.5% | 候选参数，待 PIT 回测裁决 |
| 最小量比 | 1.5 | 候选参数，待 PIT 回测裁决 |
| 最小收盘位置 | 0.60 | 延续当前强势收盘定义 |

0.5% 和 1.5 倍不是发布结论。实现必须能同时回放严格阈值作为对照，最终默认值只能由 PIT 样本、成本后收益和稳定性共同决定。

### 4.2 STRICT_GAP 标签

STRICT_GAP 不是新策略，而是 SHORT_GAP 中的高质量子集标签。V0 定义延续当前严格口径：

- 缺口不低于 1%；
- 量比不低于 2.0；
- 平台前 20 日前复权涨幅不低于 10%；
- 前 10 日平台振幅不高于 12%；
- 前 10 日平台首尾漂移绝对值不高于 8%；
- 其余 SHORT_GAP 硬条件全部满足。

默认候选流不得只返回 STRICT_GAP。每个候选必须暴露 `SHORT_GAP`，以及是否同时属于 `STRICT_GAP`。

### 4.3 从 Hard Gate 下调为 Score/Tag 的条件

以下三项不再单独淘汰 SHORT_GAP，但原始值必须保留并参与质量评分、解释和风险标签：

| 当前规则 | 调整后用途 |
|---|---|
| 平台前 20 日涨幅必须 ≥10% | 前置趋势质量、STRICT_GAP 标签、排序 |
| 前 10 日平台振幅必须 ≤12% | 平台质量、STRICT_GAP 标签、排序 |
| 平台首尾漂移绝对值必须 ≤8% | 趋势稳定性、STRICT_GAP 标签、排序 |

趋势概念没有被删除；只是从“必须已经非常成熟”改为“评价启动背景质量”。

## 5. D1 承接裁决

D1 只使用 D1 收盘时已经完整可见的数据，必须产生下列互斥结果：

| D1 状态 | 几何条件 | D2 资格 |
|---|---|---|
| 完整回补 | `D1.low <= gap_floor` | 永久失效，不允许进入 |
| 部分回补后强势收回 | `gap_floor < D1.low < gap_top` 且 `D1.close >= gap_top` | V0 允许进入，并标记部分回补风险 |
| 部分回补但未收回 | `gap_floor < D1.low < gap_top` 且 `D1.close < gap_top` | V0 不进入默认 D2 候选，保留观察记录 |
| 完全未回补 | `D1.low >= gap_top` | 允许进入，属于更强承接 |
| 停牌、缺日线或无效数据 | 无法可靠判断 | 不允许进入，状态为不确定 |

“部分回补后强势收回”的 V0 定义只使用原始缺口边界，不新增振荡指标。D1 收盘位置、缺口保留比例、日内稳定性和成交量作为 D1 质量分量输出；是否需要额外硬阈值留给 PIT 对比，不由开发人员自行添加。

## 6. 交易资格与持仓语义

- D1 收盘通过承接确认后，D2 才出现交易资格；不得用 D1 开盘或收盘价虚构成交。
- 首轮基准回测以 D2 首个可成交价格作为规范事件入口。D2 停牌或一字涨停时必须记录为不可成交，不得默认用理论开盘价填充。
- 是否允许延迟至 D3 入场属于待回测裁决项。必须与“只允许 D2”分组报告，不能悄悄沿用当前最多等待 3 日的逻辑。
- 推荐服务表达的是“策略交易资格”，不是用户真实持仓；只有回测事件或未来显式订单数据才能使用“已持仓”语义。
- D2、D3 的缺口保持、部分回补、收盘强度和价格稳定性应进入持仓验证轨迹。若原始缺口完整回补，记录核心失效事件并按 T+1 可执行时间退出。
- 固定期限结果至少分别计算实际入场后的 1、2、3、4、5 个交易日，不再以 10 日作为本策略主要结论。
- 最大持有窗口只能在 4 日或 5 日方案中比较，正式默认值待 PIT 回测裁决；任何方案都不得超过 5 个交易日后继续持有。

## 7. 缺口阶段

保留三类阶段：

- 同一上涨阶段中的第一个有效未补缺口：`persistent_candidate`。
- 第二个有效未补缺口：`accelerating_candidate`。
- 第三个及以后：`exhaustion_risk`，默认推荐流继续排除。

当前“固定回看 20 日并计数”的实现不能直接作为最终定义。目标是按当时可见数据识别同一上涨阶段，并在结构重置后重新计数。正式实现前必须先给出可复现、无未来数据的阶段起止规则和 fixture；不得通过事后最高价、未来回撤或新增 MACD/KDJ/RSI 来切分阶段。

在该规则完成并通过 PIT 验证前，应明确标记阶段识别为 V0，不得把第三缺口标签描述成已经可靠的趋势末端判断。

## 8. 排序口径

评分只用于 SHORT_GAP 候选排序，不是概率，也不能越过硬条件或 D1 承接裁决。

评分必须拆成两个可解释部分：

1. D0 启动质量：缺口、量比、收盘强度、突破质量、前置趋势、平台质量、缺口阶段。
2. D1 承接质量：缺口保留程度、是否部分回补及是否收回、D1 收盘强度、价格稳定程度、成交状态。

D1 信息应获得高于单一远期形态参数的影响力，但本轮不宣称某组权重最优。开发验收要求输出原始分量、归一化结果、权重和总分，使 PIT 回测可以比较权重版本且不覆盖旧结果。

## 9. 回测裁决问题

回测必须回答策略是否在“D0 跳空、D1 承接”后未来 1～3 日存在成本后优势，至少输出：

- D2 入场后的 1、2、3、4、5 日毛收益与净收益；
- 每个期限的样本数、均值、中位数、胜率、P10/P90；
- 最大有利波动 MFE、最大不利波动 MAE；
- 入场后原始缺口完整回补概率及首次回补日；
- SHORT_GAP 与 STRICT_GAP 分组表现；
- 完全未回补、部分回补后收回两种 D1 承接分组表现；
- 第 1、第 2、第 3+ 缺口分组表现；
- D2 直接入场与允许 D3 延迟入场的独立结果；
- 4 日和 5 日强制时间退出的独立结果。

正式阈值裁决必须使用 PIT 沪深 300 成分和 PIT 证券状态。当前成分快照可以验证代码链路，但只能标记为开发结果，不能用于选择发布参数。

## 10. 当前实现与目标差异

| 领域 | 当前实现 | 本轮目标 |
|---|---|---|
| D0 入口 | 1% 缺口、2倍量，趋势/平台三项均为硬门槛 | SHORT_GAP 形成较宽候选；趋势/平台降为评分，STRICT_GAP 保留严格标签 |
| 确认时钟 | D1～D3 均未完整回补，D3 才确认 | D1 决定交易资格，D2 最早进入 |
| D2/D3 | 入场前等待 | 入场后的强弱验证 |
| 默认入场 | D4，最多继续等待 3 日 | 基准为 D2；延迟至 D3 必须单独回测裁决 |
| 回测期限 | 1、3、5、10 日 | 1、2、3、4、5 日，重点 1～3 日 |
| 时间退出 | 最长周期可到 10 日 | 4/5 日方案比较，绝不超过 5 日 |
| 评分 | 只评价 D0 | D0 启动质量 + D1 承接质量 |
| 缺口阶段 | 固定回看前20日 | 同一上涨阶段内因果计数，规则需先裁决 |
| API 默认 | `confirmed`（D3 后） | D1 后已获得 D2 资格且仍在有效交易窗口的候选 |

表中短线时钟、候选分层、D1裁决、回测周期和API默认行为已经在策略版本 `2.0.0` 实现并通过fixture与真实HTTP链路验证。“同一上涨阶段”仍使用显式 `fixed_window_phase_v0` 近似，所有参数的PIT有效性仍未验证；不得据此发布最优阈值或收益结论。
